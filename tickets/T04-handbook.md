# T04: Handbook and maintainer docs: every page, decisions 0001 to 0007, README

## Context

T00 registered every page and decision record of `CONVENTIONS.md` §6 and §8 as a stub
that passes B's validator, and froze `docs/manifest.yml` and `docs/README.md`. This
ticket writes the content: a Diátaxis handbook under A's documentation contract (A
`docs/reference/documentation-contract.md`), the seven decision records in A's format
(A `docs/decisions/0002-hook-runner-and-checkers.md`), and the maintainer files: a
`README.md` that will become the PyPI long description, `CHANGELOG.md` and
`SECURITY.md`. A's T07 and T12 are the originals (A `tickets/T07-handbook.md`,
A `tickets/T12-maintainer-docs.md`); for a page with the same path, read A's finished
page and adapt it.

The product is not yet specified. No page invents it: where a page would describe
behaviour, it describes the placeholder and says the product's first ticket replaces it.

## Goal

Every page and record T00 stubbed is final and true of this repository, the README
reads correctly as a PyPI project description, `just check-docs` is green, and nothing
was added, renamed or reclassified in the manifest.

## Non-goals

- No change to `docs/manifest.yml` or `docs/README.md` (frozen). A page that needs a
  title or slug change is handed back.
- No decision 0008 (T06's).
- No licence choice. Decision 0006 records the question, the options and what blocks
  on it; the maintainer decides later.

     reserved-name argument (W `copier.yml` lines 76-81) applied to `rovo`; the

   that cite them. Ask: which claim in a record is not true of the merged tree; which
   record decides something `CONVENTIONS.md` §1 left to the maintainer; which "What
   would reopen this" is untestable.

   unchanged. `reference/commands.md` is generated by reading `just --list`, never from
   memory; `reference/cli.md` from `uv run --frozen rovo --help` and each subcommand's

   `just --show <recipe>`, and its description is checked against `CONVENTIONS.md` §4 and
   §5. The hand-back notes list each one as "shown, not run" with the reason. A run that
   leaves `uv.lock` or `.git/hooks` changed is a defect, not evidence.
5. **README, CHANGELOG, SECURITY.** `README.md`: what rovo is, its status (pre-release,
   not on PyPI), how to run it from a checkout, the documentation map's location, how
   to contribute (`just initialize`, `just check`), the licence sentence of
   `CONVENTIONS.md` §1 decision 6. Absolute URLs only for anything a PyPI reader would
   follow, since relative links break on PyPI; the README is not a registered page.
   `SECURITY.md`: report through GitHub's private vulnerability reporting; no supported
   release yet; what is in scope.
6. `just check-docs`; then render the README as PyPI would: `uv build --offline`, then
   `unzip -p dist/rovo-*.whl 'rovo-*.dist-info/METADATA'` shows the README as the

   **Adversarial review** (`CONVENTIONS.md` §14): the whole diff, before the final

   not run as written; which page contradicts a decision record or `AGENTS.md`; which
   page invents product behaviour; does any relative link in the README break on PyPI.
7. `just check`; commit.
